# 💳 BraiPay POS Game

Welcome to the **BraiPay POS Game**! This project is a complete Point-of-Sale (POS) and banking system built for tracking money and transactions in games (like Monopoly). It features an Android App that reads NFC cards, and a Web Dashboard to manage accounts and process payments.

## ✨ Features

- **NFC Card Reading:** Tap physical NFC cards on your Android phone to pay for items.
- **Web Dashboard:** Manage players, balances, and transactions from any computer browser.
- **Wireless Bluetooth Sync:** Connect the Web Dashboard directly to your phone via Bluetooth (No USB cable needed!).
- **Add & Revoke Funds:** Easily add or remove money from a player's card directly from the dashboard.
- **Dual Currency:** Supports both RSD and EUR.

## 🚀 Setup Instructions

1. **Install the App:** Download the `.apk` file from the releases page and install it on your Android phone with NFC capabilities.
2. **Open the Dashboard:** Open the Web Dashboard on your computer.
3. **Connect via Bluetooth:** 
   - Ensure Bluetooth is enabled on both your phone and computer.
   - In the Web Dashboard, click **"📶 Connect Bluetooth"**.
   - Select your phone from the browser popup.
4. **Start Playing:** Create items, tap cards on your phone, and watch the transactions sync live to the dashboard!
